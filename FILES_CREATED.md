# Files Created for Renovate + Black Duck Integration

This document lists all files created for the Renovate and Black Duck integration.

## Core Application Files

### `go.mod`
- Go module definition
- Uses Gin v1.8.0 (vulnerable version)

### `main.go`
- Simple REST API with Gin
- Endpoints: `/ping` and `/hello/:name`

## Black Duck Simulation Files

### `blackduck.json`
- Simple vulnerability format
- Contains single CVE: CVE-2023-29401 (HIGH)
- Used for simple Black Duck output simulation

### `blackduck_report.json`
- Full Black Duck scan report format
- Contains 2 CVEs:
  - CVE-2023-29401 (HIGH) - Directory traversal
  - CVE-2023-26125 (MEDIUM) - Denial of service
- Includes scan metadata and severity summary

### `simulate_blackduck.py`
- Simulates Black Duck vulnerability scanning
- Reads both JSON formats
- Generates Renovate package rules
- Command-line options: `--simple`, `--report`

### `generate_renovate_rules.py`
- Generates Renovate configuration from Black Duck findings
- Creates separate package rule for each vulnerability
- Outputs `renovate-blackduck-generated.json`
- Ensures 1 PR per CVE fix

## Renovate Configuration

### `renovate.json`
- Main Renovate configuration
- Configured for separate PRs per vulnerability
- Includes custom PR templates with CVE details
- Package rules for Gin security updates

**Key settings:**
- `prConcurrentLimit: 0` - No limit on concurrent PRs
- `separateMinorPatch: true` - Separate PRs
- `groupName: null` - Don't group updates
- Custom PR titles with CVE information
- Security labels: `security`, `blackduck`, priority levels

## GitHub Actions Workflows

### `.github/workflows/renovate.yml`
- Self-hosted Renovate workflow
- Runs hourly via cron schedule
- Can be triggered manually
- Processes Black Duck findings before creating PRs
- Requires `RENOVATE_TOKEN` secret

**Triggers:**
- Schedule: Every hour
- Manual: workflow_dispatch
- Push to main (on config changes)

### `.github/workflows/blackduck-integration.yml`
- Black Duck integration workflow
- Simulates Black Duck scans
- Generates Renovate rules dynamically
- Uploads scan reports as artifacts
- Runs daily at midnight

**Features:**
- Detects vulnerabilities from JSON files
- Generates dynamic Renovate config
- Comments on existing PRs with findings

## Key Features

### 1. Separate PRs per Vulnerability
- Each CVE gets its own PR
- No grouped updates for security issues
- Individual tracking and remediation

### 2. Rich PR Content
- CVE ID and severity
- CVSS score
- Vulnerability description
- Current and fixed versions
- Remediation steps
- Black Duck branding

### 3. Automated Workflows
- Hourly Renovate runs
- Daily Black Duck scans
- Manual trigger options
- Artifact uploads

### 4. Dynamic Rule Generation
- Reads Black Duck JSON reports
- Generates Renovate rules automatically
- Supports multiple vulnerability formats
- Extensible for additional data sources
